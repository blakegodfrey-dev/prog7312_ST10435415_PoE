**Persistence qualification:** active incident labels/notes are held in `IncidentTracker` memory and are not rehydrated after API restart. UI navigation can retain them while the API/episode exists. Attachments, commands, interactions, telemetry and gateway receipts have separate durable storage. Labels/notes are edited in the Command Stream incident cards; they are not a SensorDetail notes form. The earlier documentation wording implying persistent notes is corrected in Pillar 5; that correction is a source-review finding, not an invented lecturer comment.
